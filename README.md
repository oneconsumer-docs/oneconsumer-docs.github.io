## Local Development

### Prerequisites

- Ruby (2.7 or higher)
- Bundler
- Git

### Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Anurag-wednesday/ocs-docs.git
   cd ocs-docs
   ```

2. **Install dependencies:**
   ```bash
   bundle install
   ```

3. **Run local server:**
   ```bash
   bundle exec jekyll serve
   ```

4. **View in browser:**
   Open http://localhost:4000/ocs-docs/

### Build for Production

```bash
bundle exec jekyll build
```

The site will be generated in the `_site` directory.

## Deployment to GitHub Pages

### Initial Setup

1. **Push to GitHub:**
   ```bash
   git add .
   git commit -m "Initial commit: OneConsumer documentation site"
   git push origin main
   ```

2. **Enable GitHub Pages:**
   - Go to repository Settings
   - Navigate to "Pages" section
   - Under "Source", select branch: `main`
   - Select folder: `/ (root)`
   - Click "Save"

3. **Wait for deployment:**
   - GitHub Pages will automatically build and deploy
   - Check the "Actions" tab to see build progress
   - Site will be live at: https://anurag-wednesday.github.io/ocs-docs/

### Automatic Deployment

Every push to the `main` branch will automatically trigger a rebuild and deployment.

**To update the site:**
```bash
# Make your changes
git add .
git commit -m "Update: description of changes"
git push origin main
```

GitHub Pages will rebuild the site automatically (takes 1-2 minutes).

## Adding New Content

### Create a New Page

1. **Create markdown file:**
   ```bash
   # For a new "Why" page
   touch docs/why/new-topic.md
   ```

2. **Add front matter:**
   ```yaml
   ---
   layout: doc
   title: "Your Question as Title?"
   description: "SEO-friendly description including 'oneconsumer.money'"
   ---
   ```

3. **Write content:**
   - Use question-driven headings
   - Keep language conversational
   - Include examples with real numbers
   - Link to relevant pages
   - End with CTA to oneconsumer.money

4. **Update navigation:**
   - Add link to `_layouts/doc.html` sidebar
   - Add to `_config.yml` navigation if top-level

### Content Guidelines

**Tone:**
- Conversational (like texting a friend)
- No jargon without explanation
- Empathetic and non-judgmental
- Actionable and practical

**Structure:**
- Start with the core question
- Use real examples with Indian Rupees
- Break complex topics into simple steps
- Include "Ask OneStep" prompts
- Link to oneconsumer.money

**SEO:**
- Include target keywords naturally
- Use descriptive headings (H2, H3)
- Internal links to related pages
- Meta description under 160 characters

## Customization

### Update Brand Colors

Edit `assets/css/main.css`:
```css
:root {
  --navy: #302E4C;
  --purple: #854DDD;
  --light-purple: #D2CCFF;
  --accent: #DBF58A;
  --white: #FFFFFF;
}
```

### Update Site Metadata

Edit `_config.yml`:
```yaml
title: "OneConsumer Documentation"
description: "Your description here"
url: "https://anurag-wednesday.github.io"
baseurl: "/ocs-docs"
```

### Add New Section

1. Create directory: `mkdir docs/new-section`
2. Add to navigation in `_config.yml`
3. Update sidebar in `_layouts/doc.html`
4. Create index page: `docs/new-section/index.md`

To add Google Analytics or PostHog:

1. Edit `_includes/head.html`
2. Add tracking script before `</head>`
3. Or add to `_config.yml` for Jekyll Analytics plugin

## Troubleshooting

### Site not updating after push

1. Check GitHub Actions for build errors
2. Verify `_config.yml` syntax
3. Clear browser cache
4. Wait 2-3 minutes for propagation

### Local development issues

**Bundler errors:**
```bash
bundle update
bundle install
```

**Port already in use:**
```bash
bundle exec jekyll serve --port 4001
```

**Build warnings:**
Check `_config.yml` for invalid YAML syntax
